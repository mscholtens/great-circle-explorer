# Executive summary — Great Circle Explorer

**What it is.** A small web application for a home lab. The user picks two points on a 3D globe (by clicking, or by typing coordinates in the left-hand panel) and instantly sees how far apart they are and a set of related facts: real distance over the curved Earth, bearings, flight time, minimum network latency, sunrise and sunset, time-zone difference, and more.

**What makes it different.** Every number can be inspected. Clicking a metric opens a pop-up that shows the formula, the same formula with the actual numbers substituted, the intermediate results, and the final answer. It is meant to teach how distance on a sphere is really calculated using sine, cosine and related functions.

**How it works.** A Python backend (FastAPI) does *all* the math using only the standard `math` module on a spherical Earth, with no geodesy libraries. A plain JavaScript frontend (Vite, MapLibre GL JS, KaTeX) only draws what the backend returns. The two run as separate processes started by hand.

**Runs fully offline.** No internet connection and no external API calls are needed at runtime. Libraries are bundled, and the map is drawn from locally stored country outlines, labels, and time-zone boundaries.

**Scope.** 25 metrics (plus two optional ones: the point reached from A on a bearing and distance, and a return trip) in four groups (Geometry, Through the Earth, Travel, Sun & time), including the places where the route crosses the equator, the tropics, the polar circles and the 0° and 180° meridians, a flight time split into airborne time and gate-to-gate time with the courses after take-off and before landing, time zones for any date from 1970 to 2049, and a **distance analysis** that lines up ten ways of measuring the same two points (straight tunnel, the great circle on three different spheres, Vincenty and Lambert on the WGS84 ellipsoid, rhumb line, equirectangular shortcut, flat grid, flat Mercator ruler), each tagged with the Earth model it assumes and compared with the Vincenty reference, so the effect of the method and the effect of the model can be told apart, and comparisons that put the spherical result in context: the WGS84 ellipsoid, a flat Mercator map, the rhumb line and the size of the Earth. A toolbar on the map switches the layers, shows the airports, draws circles of equal distance and shades the night side of the Earth for a date and time picked with a friendly picker, and the live coordinates under the pointer are shown at the bottom. A start point plus a course and a distance can be entered instead of a second point, and the app finds the destination. Points can also be set by airport code or city name from a bundled offline list, the map can be flat or a globe, distances can be shown in km, nautical or statute miles, a link restores a scene, and the results can be exported as a PDF with a choice of metrics and optionally the full calculation. Educational accuracy, not survey accuracy: on a spherical Earth distances can be about 0.5 % off and bearings a fraction of a degree, which is measured and documented in `docs/ACCURACY.md`. **The project is for learning and exploration only, not for production use or real-life navigation**, and is released under the MIT License.

**Not in scope.** User accounts, databases, real flight routing or winds, fuel/CO₂ estimates, place search, containers or cloud hosting.
